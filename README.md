# Ferramenta de teste de usabilidade (ISO 9241-10)

Esta ferramenta permite testes de usabilidade de sistemas de acordo com a ISO 9241-10. \
Ela foi feita utilizando a linguagem Racket para a disciplina de Programação Lógica e Funcional do curso de bacharelado em Ciência da Computação do IFC Videira.

**Alunos:** Henrique Pieri de Lima e Alexandre Willian de Bastiani

## Execução

Basta clonar este repositório e compilar o arquivo ```main.rkt``` no compilador de Racket da sua preferência (para desenvolvimento, utilizamos o DrRacket e o recomendamos).

É necessário ter os arquivos ```main.rkt``` e ```banco.sqlite``` no mesmo diretório.

Para criação da tabela no banco de dados, há o arquivo ```criar-tabela.sql```.

## Relatório

Neste mesmo repositório temos o relatório em PDF que fala sobre a ISO, o processo de desenvolvimento e teste de usabilidade do DrRacket (que também já está inserido no banco de dados).
